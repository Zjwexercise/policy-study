# 考研政治刷题掌上宝 (PolicyMaster) 🎓

专为全国硕士研究生招生考试（考研政治）量身定制的跨平台交互式刷题与错题突破系统。支持 **PC端与手机端随时随地同步使用**，支持上传并智能解析各种常见考研政治题集 PDF（如肖秀荣1000题、徐涛优题库、腿姐背诵手册、历年真题等）。

---

## 🌟 核心特色功能

1. **跨平台支持（电脑 + 手机完美适配）**
   - **PC 电脑端**：支持键盘快捷键高效刷题（`A`/`B`/`C`/`D` 或 `1`/`2`/`3`/`4` 快捷选定，`Enter` 提交多选题，左右方向键或 `J`/`K` 翻题）。
   - **手机移动端**：自适应手机竖屏排版，界面风格媲美原生 App。点击电脑端右上角 **【手机扫码刷题】**，手机直接扫码或在浏览器输入局域网地址，即可在自习室、床上或通勤路上随时随地刷题。

2. **考研政治 PDF 智能解析引擎**
   - 采用 PyMuPDF 高性能页面解析，具备**双栏/多栏排版智能识别**能力，避免考研真题集左右栏串行。
   - 自动识别 **单选题（1分）** 与 **多选题（2分）**。
   - 智能提取题干、选项（A/B/C/D）、参考答案及考点解析。
   - 支持**题解一体化编排**与**题目在前面、答案解析在文末/章末**等多种常见 PDF 格式。

3. **双重刷题模式**
   - **刷题/背题模式（做一题即时看解析）**：考研政治核心刷法！作答后立即比对正误，选项用绿色（正确）和红色（错选）直观高亮，即时弹出该题考点精析。
   - **乱序与分类专项练习**：支持按学科模块筛选（马原、毛中特/习思想、史纲、思修法基、形势与政策），支持乱序随机练习。

4. **智能错题本（消灭错题）**
   - 凡是作答错误的题目，系统**自动收录进错题本**，并记录做错次数与最近错选项。
   - 提供“标记为已掌握（移出错题本）”功能，专治考研政治陷阱题。

5. **考点专属笔记功能**
   - 每道题目均可随时记录你的备考心得、记忆口诀、避坑提醒与真题联想。
   - 独立 **【考点笔记】** 专区，考前冲刺阶段支持一键搜索与导出/复制所有笔记。

6. **二刷 / 三刷进度重置**
   - “政治选择题至少刷三遍”——每个练习册均支持一键重置刷题进度，保留题库的同时清空作答痕迹，随时开启全新一轮二刷。

7. **内置经典示范题库**
   - 首次启动即自带 15 道精选真题级考研政治核心选择题（覆盖马原辩证法、认识论、政经、毛中特、新质生产力、史纲转折会议、思修核心价值观等），开箱即用体验！

## 🚀 启动与使用方式

### 方式 1：双击一键启动（推荐，Windows）
双击根目录下的 **`start.bat`** 即可。
终端将自动输出访问网址并自动在电脑默认浏览器打开：
```
================================================================
 🎓 考研政治刷题掌上宝 (PolicyMaster) 正在启动...
================================================================
 [电脑浏览器访问]  ->  http://localhost:8000
 [手机自习室/床上] ->  http://192.168.x.x:8000
 (手机连接同一Wi-Fi或手机热点，扫描界面右上角二维码即可同步刷题)
================================================================
```

### 方式 2：命令行启动
在项目根目录下运行：
```powershell
python run.py
```

---

## 📱 手机端使用指南

1. 确保手机与电脑连接在**同一个 Wi-Fi**（或者电脑连接手机开的热点）。
2. 在电脑端点击右上角的 **【手机扫码刷题】** 绿色按钮。
3. 用手机微信/系统相机扫一扫二维码，或在手机浏览器中输入屏幕上显示的 `http://192.168.x.x:8000`。
4. **小技巧**：在手机浏览器中点击“添加到主屏幕”，即可像原生 App 一样全屏无边框随时刷题！

│   └── routers/              # API 路由

│       ├── questions.py      # 题目获取与校对修改
│       ├── practice.py       # 答题判定与统计
│       ├── wrong_book.py     # 错题本管理
│       ├── notes.py          # 笔记管理
│       └── system.py         # 局域网 IP 与扫码接口
├── frontend/                 # Vue 3 + Tailwind CSS 前端
│   ├── src/
│   │   ├── components/       # 刷题、错题本、笔记、练习册、统计各组件

│   │   └── api.js            # 前后端交互 SDK
│   └── dist/                 # 预编译生产静态资源
├── run.py                    # 主运行脚本（自动开浏览器与检测局域网）
